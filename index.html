Panduan Setup & Integrasi Firebase & GitHub

Ikuti langkah-langkah di bawah untuk menghubungkan website ini ke Firebase Realtime Database dan men-deploy-nya ke GitHub Pages.

1

Konfigurasi Firebase Realtime Database

  1. Buka Firebase Console dan buat project baru.
  2. Masuk ke menu Build > Realtime Database dan klik Create Database.
  3. Atur Rules database agar bisa dibaca/ditulis publik (atau gunakan auth sesuai kebutuhan): 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  4. Masuk ke Project Settings > General, lalu daftarkan Web App baru untuk mendapatkan objek konfigurasi Firebase.
  5. Klik tombol Konfigurasi DB di pojok kanan atas aplikasi ini dan masukkan kredensial Firebase Anda.
2

Deploy ke GitHub & GitHub Pages

  1. Buat repository baru di GitHub (misal: kas-mpk-sman14sby).
  2. Simpan kode file ini dengan nama index.html.
  3. Upload file index.html tersebut ke repository GitHub Anda via browser atau perintah Git: 
    git init
git add index.html
git commit -m "Initial commit Kas MPK SMAN 14"
git branch -M main
git remote add origin https://github.com/USERNAME/repo-name.git
git push -u origin main
  4. Masuk ke tab Settings di repository GitHub Anda > Pages.
  5. Pada bagian Build and deployment, pilih Source: Deploy from a branch, branch: main, folder: /(root), lalu klik Save.
  6. Website Anda akan aktif secara otomatis dalam beberapa menit!
